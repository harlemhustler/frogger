# Frogger’s Gorgon Shopify integration

This directory owns the Frogger operation planner, folder picker, and folder carousel source for the Gorgon Shopify demo. Copy the JavaScript to Gorgon’s `Shared Gorgon/shopify-gorgon/assets/` and the Liquid snippet to `Shared Gorgon/shopify-gorgon/snippets/` when releasing. Gorgon owns the dashboard shell, shared responsive styles, and deployed copies. The standalone Frogger service remains in this repo. Shopify previews folder entries using browser APIs and does not run the operation chain.
